# Portfolio — alvaromartinruiz.github.io

Personal site built with [Hugo](https://gohugo.io) (extended) and Tailwind CSS v4.
Deployed automatically to GitHub Pages by the `.github/workflows/hugo.yml` workflow on every push to `main`.

---

## Repo layout

```
.
├── content/                  # Markdown content (what you write)
│   ├── blog/                 # Blog posts (one .md per post)
│   ├── work/                 # Per-project write-ups (one .md per project)
│   └── projects.md           # The /projects index page wrapper
│
├── data/                     # Site data (the easiest stuff to edit)
│   ├── profile.json          # Name, tagline, location, photo
│   ├── projects.json         # All projects (with featured flag / order / stack)
│   ├── social.json           # Social links shown in the hero
│   └── about_me.json         # "About" section text
│
├── assets/
│   ├── main.css              # Tailwind v4 source + custom CSS (gradients, accordion, etc.)
│   └── images/profile.jpeg   # Source image for the generated OG share card
│
├── static/                   # Files served as-is at the site root
│   ├── favicon.svg / .png    # Browser tab icons
│   ├── Alvaro_Martin_CV.pdf  # CV download
│   └── images/               # Public images referenced by content
│
├── layouts/                  # Hugo templates (override the theme)
│   ├── _default/
│   │   ├── baseof.html       # Outer HTML shell (header, footer, background)
│   │   ├── single.html       # Blog post page
│   │   ├── list.html         # Blog list page
│   │   └── projects.html     # Projects archive page (with search + filters)
│   ├── work/                 # Per-project write-up layouts
│   ├── partials/             # header, footer, head, etc.
│   ├── index.html            # Home page
│   └── 404.html              # Custom 404
│
├── themes/aafu/              # Base Hugo theme (git submodule, mostly overridden)
├── config.yaml               # Site config: title, baseURL, markup, etc.
├── package.json              # Tailwind v4 dependency
├── tailwind.config.js        # Tailwind config (dark mode, typography plugin)
└── .github/workflows/hugo.yml  # CI: build with Hugo + Pagefind, deploy to Pages
```

The `public/` and `resources/` folders are **generated by Hugo and ignored** — never commit them; CI rebuilds the site from source on every push.

## Deploy

```powershell
cd c:\_Alvaro\portfolio-website
hugo                 # optional: sanity-check it builds with no errors
git add -A
git commit -m "describe your change"
git push origin main
```

Pushing to `main` triggers the GitHub Actions workflow (`.github/workflows/hugo.yml`), which:
1. Sets up Hugo (pinned to `0.158.0` extended) and Node.
2. Builds the site with `hugo --minify` and runs Pagefind for search indexing.
3. Deploys `public/` to GitHub Pages.

Live in ~1–2 minutes at <https://alvaromartinruiz.github.io>. Watch the **Actions** tab for status.

## Conventions

- **Reading time** on blog posts shows Hugo's auto-calculated value, but can be overridden per post with `readingMinutes: 20` in the front matter.
- **Featured projects** on the home page are the ones in `data/projects.json` with `"featured": true` — sorted by `featured_order`.
- **Per-project write-ups**: featured projects link to `/work/<slug>/` (a content page in `content/work/`); other projects link straight to GitHub.
- **Math** in blog posts uses standard LaTeX delimiters (`$...$`, `$$...$$`) rendered with KaTeX.
- **Code blocks** are highlighted with Hugo's Chroma (`github-dark` theme).

## Notes

- The base theme lives in `themes/aafu/` as a git submodule — most files have been overridden in `layouts/`, but pulling submodule updates may surface conflicts. Clone with `git submodule update --init --recursive`.
- The OG share card at `assets/images/profile.jpeg` is processed at build time (darkened + name overlaid) and used as the default social-share preview for every page.
